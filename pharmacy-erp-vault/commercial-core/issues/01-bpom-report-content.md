## Question

What must each BPOM/SIPNAP compliance report (OOT, Prekursor, Psikotropika/Narkotika) contain for a pharmacy in Indonesia — the required columns, date windows, and any signature/approval fields? And which legal source (Permenkes/BPOM regulation) specifies each report?

## Answer

Resolved by researcher subagent (cli-proxy/gemini-3.1-pro-low). Full brief: `.pi-subagents/artifacts/outputs/b042f11c-7b49-4545-b054-9a1bb56b04f8/research.md`.

- **Reports required**: Narkotika, Psikotropika, Prekursor, OOT (Obat-Obat Tertentu).
- **Cadence**: monthly, due by the 10th of the following month.
- **Signature**: Apoteker Penanggung Jawab (APJ) signature + license details required on each report.
- **SIPNAP columns** (all categories): Product Name, Initial Stock (Saldo Awal), Incoming Qty (Pemasukan), Outgoing Qty (Pengeluaran), Destruction Status (Status Pemusnahan), Final Stock (Saldo Akhir).
- **Legal basis**: BPOM Reg 24/2021 (OOT + Prekursor oversight), Permenkes 5/2023, Permenkes 73/2016 (mandatory Kartu Stok, still active).
- **Gap**: exact OOT Excel template headers may vary from the standard form; core movement columns identical.
