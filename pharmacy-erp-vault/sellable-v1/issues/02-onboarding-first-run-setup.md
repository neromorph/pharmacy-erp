# Onboarding / first-run setup

Type: task
Status: resolved

## Question

What is smallest first-run setup flow that lets a new tenant reach first sale without hand-holding?

## Answer

Current app has settings page for identity, logo, license, and SATUSEHAT. That is data entry, not guided onboarding.

Smallest sellable v1 flow:
- One first-run checklist on app shell.
- Steps: company identity, opening shift, staff role check, one supplier, one product, one batch, one sale.
- Show progress and direct links to exact page for each step.
- Hide advanced setup behind later settings.
- Reuse current settings and master data pages. Do not build a full wizard now.

This is enough to get a new tenant to first sale without hand-holding.
