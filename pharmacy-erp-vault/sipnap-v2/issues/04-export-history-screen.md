## Answer

1. Tab on `/reports/sipnap`: [Generate Report] [History]. One unified page.
2. Columns: Month, Year, Generated At, Generated By (user email), Row Count, Hash/Status.
3. Stored snapshot: on generate, push the exact CSV payload to Supabase Storage bucket `sipnap-archives` (tenant-scoped RLS) and store the URL on the history row. Re-download serves the stored file — never recompute.
4. Newest-first, basic pagination (12 rows/year; no filters needed).
